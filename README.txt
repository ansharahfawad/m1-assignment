ABOUT THE PROJECT

Happy Tails is a sample local pet adoption website.
It contains two HTML pages: a home page and a page
showing pets available for adoption.

REQUIREMENTS COVERED

1. Two HTML pages
2. Headings and paragraphs
3. Ordered and unordered lists
4. Text links and page navigation
5. Images with alternative text
6. An HTML table
7. An images folder
8. External resource links
9. Shared CSS styling

HOW TO RUN

1. Open the project folder in VS Code.
2. Add the required images to the images folder.
3. Open index.html in a browser.
4. Click Meet the Pets to open pets.html.

GITHUB SUBMISSION

1. Create a repository named m1-assignment.
2. Commit and push the project as you develop it.
3. Make at least three commits and pushes.
4. Submit your GitHub repository URL as instructed.

NOTE
